# Problem Statement
People often forget where their money goes in daily spending.  
This tool helps in tracking expenses in a simple and organised way so users can understand their spending pattern.

# Scope of the Project
The project is designed for personal use.  
It can handle small day-to-day expenses and show how much money has been spent overall.

# Target Users
- Students  
- Beginners learning Python  
- Anyone who wants a simple expense tracking tool

# High-Level Features
- Add expense  
- Show all expenses  
- Calculate total spending.  
- Simple menu-driven interface.
