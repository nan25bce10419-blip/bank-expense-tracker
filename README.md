# bank-expense-tracker
I made a bank expense tracker in this project.

#Overview of the project
-This project is a simple Python-based expense tracker that helps users record their daily expenses.  
-It stores the date, purpose, and amount spent, and also shows all records and total spending.  
-The project is made to practice basic Python concepts like loops, lists, and functions.

#Features
- Add a new expense with date, purpose, and amount.
- Show all saved expenses.  
- Calculate total money spent.  
- Simple text-based menu.  
- Easy to understand and run.

#Technologies / Tools Used
- Python 3  
- Functions  
- Lists (to store data)  
- Basic input/output commands

#Steps to Install & Run the Project
1. Install Python 3 if not installed. 
2. Download or clone this repository.  
3. Open the project folder.  
4. Run this command in terminal.
5. Use the menu to perform different actions.

#Instructions for Testing
- Choose *1* to add expense.
- Choose *2* to display all expenses. 
- Choose *3* to see total amount spent.  
- Choose *4* to exit the program.  
- Try entering wrong inputs to check error-handling (like letters instead of numbers).
